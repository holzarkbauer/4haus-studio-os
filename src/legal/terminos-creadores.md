# Términos del Programa de creadores 4haus

> **Borrador para revisión de un abogado antes de publicarlo.** Los datos entre [corchetes] se completan antes de usarlo.

Estos términos rigen el uso de 4haus Studio por los **creadores**: personas que usan la plataforma para crear webs, chatbots y agentes de IA y venderlos a sus propios clientes. 4haus Studio es el nombre comercial de [Nombre completo de José Trujillo], RUC N.° [10…].

## Cómo entras

1. Pides tu código de acceso en la página **Creadores**, con tu cuenta de Instagram.
2. Lo canjeas iniciando sesión con Google. El código es personal y de un solo uso.
3. 4haus revisa tu solicitud y activa tu cuenta. Te comprometes a publicar contenido sobre tu trabajo con la plataforma.

## Cómo pagas y cuánto ganas

**Lo que cobras a tus clientes es 100% tuyo.** 4haus no cobra comisión sobre tus ventas. Puedes elegir una de dos formas de pago:

| | Opción 1 · Pago por web | Opción 2 · Suscripción mensual |
| --- | --- | --- |
| Qué pagas a 4haus | El 50% del precio de lista del paquete, una vez por web | Un plan mensual: 0 USD (hasta 3 maquetas), 1 USD (prueba de 7 días), 7, 27 o 47 USD al mes |
| Precio de lista de referencia | Landing 3D 500 · Web profesional 1.000 · Web + ventas 2.000 · Sistema completo 3.000 USD | — |
| Qué incluye | Esa web sin marca de agua, lista para publicar | Las webs y herramientas que permita tu plan |
| Lo que cobras a tu cliente | Lo decides tú; es 100% tuyo | Lo decides tú; es 100% tuyo |

- La suscripción se renueva cada mes y puedes cancelarla cuando quieras; se mantiene activa hasta el final del mes pagado.
- Hosting, dominio y mantenimiento de las webs de tus clientes se contratan aparte, según los precios vigentes.
- **Referidos:** ganas el 10% si alguien compra el Curso o el Modelo de negocio con tu código (ver las Condiciones de venta).

## Tus responsabilidades

1. **Con tus clientes:** tú les vendes, fijas el precio, les cobras y respondes por lo que les prometes. 4haus no es parte de ese contrato.
2. **Contenido legal:** no crees webs para actividades ilegales, engañosas, de odio o que copien marcas, personajes o textos de terceros sin permiso.
3. **Datos personales:** si tus webs captan datos de personas, informa y pide permiso como exige la ley de tu país (en el Perú, la Ley 29733).
4. **Contacto con prospectos:** escribe solo a los canales que cada negocio publica, respeta a quien pide no ser contactado y las listas "No llamar" / "Gracias… No insista".
5. **Sin promesas de ingresos:** no prometas a nadie ganancias usando el nombre de 4haus.

## La plataforma

- Las plantillas, el software y la marca 4haus son de 4haus. Las webs que creas para tus clientes son de ellos una vez pagadas.
- Las webs creadas con IA pueden contener errores: revísalas antes de entregarlas.
- 4haus puede suspender una cuenta que incumpla estos términos, avisando el motivo por correo.
- 4haus trata tus datos conforme a la Ley 29733. Puedes pedir acceso, corrección o eliminación en [correo de 4haus].
